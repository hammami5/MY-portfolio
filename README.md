## Run locally

No build step. Just open the folder:

1. Download or clone the repository.
2. Open `index.html` in your browser.
   - Tip: use a local server for the cleanest experience:
     `python -m http.server 8080` → `http://localhost:8080`

## Deploy on GitHub Pages

1. Create a repository, e.g. `MY-portfolio`, and upload the **contents** of this folder (not the folder itself).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Select the branch `main` and folder `/ (root)`.
5. Save — the site goes live at `https://<your-username>.github.io/MY-portfolio/`.

> The `index.html` file must stay in the repository root. All asset paths are relative, so everything works on GitHub Pages with no extra configuration.
